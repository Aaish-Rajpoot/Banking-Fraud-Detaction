# Banking-Fraud-Detaction
Simulates a banking system with basic account management (deposit/withdraw) and balance tracking. This project provides a foundation for fraud detection features like transaction monitoring and detecting suspicious activities or anomalies within transactions.

## Description
Manages user accounts, supports transactions, and lays the groundwork for fraud checks.

## Features
- Create accounts
- Deposit/Withdraw
- Balance tracking

## Run
```bash
g++ main.cpp bank.cpp -o bank
./bank
